重点比较：统一批次参数、少量文件例外、组合预设、预检与执行反馈。点击一个方案进行选择。

C · 分步向导

文件 → 参数 → 例外 → 预检 → 执行

①文件　②预设　③例外　④预检　⑤执行

引导性最好，适合低频用户；频繁修改和反复检查时步骤较多，操作效率偏低。

我的建议：选择 B。表格只显示文件名、状态、参数摘要和“已覆盖”标记；形状、旋转、折手、标识页的完整控件放在批次配置区与右侧详情区，不把几十个字段铺成几十列。
