# 材料选择框：临时排版参数窗口与手动布局计划

## 目标

在不挤占 `MaterialSelectFormModern` 现有界面的前提下，从其现有全窗体右键菜单打开独立的“临时排版参数”窗口。该窗口编辑仅对当前材料选择对话框有效、且能随材料预设保存的参数。材料选择框原有的行数、列数结果标签改为可输入控件；既有旋转方向 UI 继续承担旋转切换。

## 已确认的现状

- `MaterialSelectFormModern` 已通过 `WndProc` 捕获 `WM_CONTEXTMENU`，并展示 `_presetContextMenu`，见 `src/WindowsFormsApp3/Forms/Main/MaterialSelectFormModern.cs:4437-4468`。
- 右键菜单当前包含“保存为预设”“管理预设”和预设列表，初始化于 `MaterialSelectFormModern.cs:4473-4489`。
- 排版结果目前通过 `rowsDisplayLabel`、`columnsDisplayLabel` 显示，设计器定义在 `MaterialSelectFormModern.Designer.cs:768-786`，更新逻辑在 `MaterialSelectFormModern.cs:6889-7029`。
- 当前配置从全局 `AppSettings` 读取，平张/卷装的构建入口在 `MaterialSelectFormModern.cs:6508-6714`；因此需要引入“当前窗口临时覆盖值”，而不能在编辑时直接写全局设置。
- 预设已由 `MaterialSelectionPreset` 加载/保存；保存入口 `MaterialSelectFormModern.cs:4747-4828`，应用排版相关字段入口 `MaterialSelectFormModern.cs:5063-5128`。

## 设计决策

### 临时配置的生命周期

在 `MaterialSelectFormModern` 内维护一个私有临时配置对象；对话框打开时以全局自动排版设置为初始值，独立窗口“应用”后仅替换该对象并重新计算。不在独立窗口中调用 `AppSettings.Set`，避免污染全局默认值。

保存预设时序列化当前临时配置；加载预设时恢复为当前窗口的临时配置。缺少新增字段的旧预设应回退到全局默认值，以保持兼容。

### 手动行列与卷装最小长度

- 行、列输入为空或 `0` 表示自动；正整数表示用户期望值。
- 平张：手动行列必须在可印刷区域内成立；不成立则保持输入值、显示不可行原因，不静默缩小。
- 卷装：固定宽度永远不可编辑。列数先校验宽度；行数作为期望下限；最小长度也是下限。最终行数取“期望行数”和“满足最小长度所需的最少行数”的较大值。
- 卷装的实际排版长度为 `上边距 + 最终行数 × 旋转后的单页高度 + 下边距`，必须不小于最小长度。
- 旋转仍复用现有 `0°/270°` 结果与交互；计算时先考虑 PDF 自带页面旋转，再应用布局旋转，禁止重复叠加。

## 实施步骤

1. 新增临时配置模型与预设字段。
   - 在 `src/WindowsFormsApp3/Models/` 新增轻量的 `TemporaryImpositionParameters`（或放入 `ImpositionModels.cs`，以项目现有模型组织为准）。
   - 字段包括：材料类型、平张宽高、平张尺寸解锁状态、卷装固定宽度、卷装最小长度、四边距、请求行数、请求列数、卷装旋转模式/强制旋转状态。
   - 扩展 `MaterialSelectionPreset.cs`：保存上述临时参数；新增字段全部提供默认值，保证旧 JSON 能反序列化。

2. 新增独立的临时参数窗体。
   - 新建 `src/WindowsFormsApp3/Forms/Main/TemporaryImpositionParametersForm.cs` 与 Designer 文件。
   - 使用 AntdUI 优先实现输入和按钮；按当前材料类型显示对应区域。
   - 平张：宽高默认禁用；“解锁纸张尺寸”复选框勾选后启用。四边距可编辑。
   - 卷装：固定宽度始终禁用；最小长度和四边距可编辑。
   - 提供“应用”“取消”；应用前校验正数、边距非负、平张可印刷区域为正、卷装可用宽度为正。窗口只返回配置副本，不写 `AppSettings`。

3. 将独立窗口接入材料选择框右键菜单。
   - 修改 `MaterialSelectFormModern.cs:4473-4489`，在预设操作之前添加“临时排版参数…”菜单项，并绑定 `OpenTemporaryImpositionParameters`。
   - 菜单点击时以当前临时配置和当前材料类型打开窗口；确认应用时替换当前窗口临时配置，刷新行列输入状态并调用已有防抖重算流程。
   - 保留 `WndProc` 的全窗体右键行为；确保右键单击输入框时不抢占其标准编辑菜单（必要时仅在窗体空白处或非文本输入控件上显示该菜单）。

4. 将行数、列数从结果标签改为可输入控件。
   - 修改 `MaterialSelectFormModern.Designer.cs:768-786`：以两个受限整数输入控件替换 `rowsDisplayLabel`、`columnsDisplayLabel`，并保留独立的“实际结果/状态”文本，防止计算结果覆盖用户意图。
   - 修改 `InitializeDisplayLabels`、主题应用与 `UpdateLayoutDisplay` 等依赖标签的代码（`MaterialSelectFormModern.cs:636-683`、`6889-7029`、`7161-7194`、`8683-8703`）。
   - 输入改变采用短防抖；空/0归为自动，正整数写入临时配置；非法输入直接标红或提示，不触发计算。

5. 让配置读取优先使用临时覆盖值。
   - 修改 `GetFlatSheetConfiguration`、`GetRollMaterialConfiguration` 与 `GetCurrentImpositionConfiguration`（`MaterialSelectFormModern.cs:6508-6714`）。
   - 先取当前窗口临时配置；未设置的字段再回退 `AppSettings`。严禁在临时编辑流程回写全局键。
   - 平张尺寸锁定只控制 UI 编辑权限；无论锁定与否都使用当前临时值参与计算。卷装固定宽度始终来自临时配置的初始默认值/预设值，但在窗口中不可手动编辑。

6. 扩展排版服务的手动约束与卷装长度下限计算。
   - 调整 `src/WindowsFormsApp3/Services/ImpositionService.cs` 中平张/卷装布局计算。
   - 平张：在强制行列或强制旋转时返回明确的可行/不可行结果与原因；不得用 `Math.Min` 静默替换用户的行列请求。
   - 卷装：固定宽度验证列数；按旋转后有效页高和上下边距计算最少行数；最终行数取最大值，并把实际使用长度写入 `ImpositionResult`。
   - 一式 N 联路径也必须复用同一份约束计算，避免标准模式与联版模式结果不一致。

7. 补齐预设读取、结果回传与提示。
   - 修改 `SaveCurrentAsPreset`（`MaterialSelectFormModern.cs:4747-4828`）存入临时配置、请求行列及旋转状态。
   - 修改 `LoadPreset`（约 `MaterialSelectFormModern.cs:5063-5128`）恢复临时配置后统一触发一次重算，避免控件事件中间态造成多次计算。
   - 扩展 `MaterialSelectionResult`/`ImpositionResult`（如需）以区分请求行列、有效行列、卷装实际使用长度与不可行状态；`FileRenamePanel` 最终只取可行的有效值。

8. 增加测试并验证构建。
   - 为临时配置/预设 JSON 兼容、平张锁定、卷装宽度不可编辑、最小长度抬升行数、旋转后尺寸交换、手动列数超宽等添加单元测试。
   - 运行 `dotnet build WindowsFormsApp3.sln -c Debug`；在可运行的 Windows 环境进行手工 UI 验证。

## 验收标准

1. 在材料选择框任意非文本编辑区域右键，可看到并打开“临时排版参数…”。
2. 平张宽高默认不可编辑；勾选解锁后可编辑；取消/关闭窗口不改变当前布局。
3. 卷装固定宽度全程不可编辑；最小长度、边距可编辑。
4. 行/列在材料选择框内可输入；空或 0 为自动；输入值在计算过程中不会被结果显示覆盖。
5. 卷装最终行数始终满足：`实际排版长度 >= 最小长度`；手动行数较大时不被长度反算降低。
6. 卷装手动列数超出固定宽度时，明确显示不可行，固定宽度不变。
7. 保存并重新加载预设后，临时参数、锁定状态、行列和旋转状态完全恢复；旧预设仍可加载。
8. 临时编辑、保存/加载预设均不改变全局自动排版设置。
9. 最终确认后的行列、布局数量和旋转角度与实际 PDF 处理一致。

## 风险与缓解

- 现有 `WndProc` 会为整个窗体拦截右键：需避免覆盖文本输入控件的原生剪切/复制/粘贴菜单。
- 当前行列标签在多处被查找与更新：替换控件后需系统性更新初始化、主题、清空状态与重算展示代码，避免空引用或输入被覆盖。
- 现有一式 N 联走独立算法：将手动约束封装为公共校验/计算函数，避免两个路径产生不同有效行列。
- JSON 预设是持久数据：新增字段必须使用安全默认值并兼容缺失字段，不能破坏用户历史预设。

## 验证步骤

1. 单元测试：给定 PDF 尺寸和边距，验证平张固定网格可行/不可行、卷装列宽校验、最小长度向上取整行数和 0/270° 两方向。
2. 手工验证：打开材料选择框，右键打开参数窗口；分别测试平张锁定、卷装固定宽度只读、应用/取消。
3. 手工验证：修改行列、最小长度、边距和旋转，确认结果和错误提示即时刷新；保存预设、重开窗口、加载预设进行复核。
4. 运行 Debug 构建与相关测试项目；确认没有修改现有全局设置值。
