方案特点分析

优点： 列表只留必异的订单/数量/尺寸，工艺相同的文件打包成组，参数统一显示在组头卡片中。
考量： 需要维护“将选中文件加入新分组”的操作逻辑。
🌟 为什么方案五最懂生产：
1. 列表里不再重复出现一模一样的材料和工艺文字，零视觉噪点。
2. 组头直接呈现该批的统筹工序（`[PET] [黑白光膜] [圆角R5]`），车间师傅一眼就分清不同工序批次。
3. 表格只保留核心 4 列，无论在多小的屏幕上都宽敞整齐！
